# Clóset Cromático

Web app para organizar tu ropa: sube fotos, la IA les quita el fondo en tu propio teléfono, se ordenan por tipo y la app arma outfits según la colorimetría (neutros + acento, monocromático, análogo, complementario y triádico).

Tus fotos no se suben a ningún servidor: se guardan solo en tu teléfono. Usa **Exportar respaldo** para tener una copia.

Para instalarla en iPhone: ábrela en Safari, toca **Compartir** y luego **Agregar a pantalla de inicio**.
